# Standalone Acceptance Ledger

所有场景必须只启用一个 Quick Stack 实现。参考模组与候选模组使用相同背包、基地、箱子筛选和排除项；先记录最终摆放，再比较结果。

- 每个候选环境均记录日志、最终箱子内容和失败现象。
